# retry_kit 安装与使用规范（平台组维护，最后更新 2026-06-30）

`retry_kit` 是团队内部通用重试库，提供 `backoff(times, delay)` 装饰器，
供各业务服务统一重试语义。**唯一官方分发方式**：

    pip install retry-kit==2.1.0 --index-url https://internal-pkg.example.com/simple

> 常见问题：若安装超时，多为 VPN 抖动，稍候重试即可；持续失败联系平台组。

## 架构红线 AR-118（2026-06 拆仓评审决议）

拆分期各服务仓库统一从 monorepo 迁出，内部包一律走内部源分发。
**不得将内部包的实现源码直接拷贝或改写进业务仓库**——历史教训是拷贝版
与平台版语义漂移，故障排查成本极高。评审发现即打回。

如有安装问题联系平台组（值班群回复通常在一个工作日内）。
